## Описание задачи
Программа выполняет умножение двух квадратных матриц \(A\) и \(B\) размерности \(NxN\) и записывает результат в матрицу \(C\).

*   **Входные данные:** Текстовые файлы, содержащие размерность \(N\) и элементы матриц \(A\) и \(B\).
*   **Выходные данные:** Файл с результирующей матрицей \(C\), а также логирование метрик (время работы, объем задачи в байтах, достигнутая производительность в GFLOPS).

## Технологический стек
*   **Язык:** C++ (стандарт C++17 / C++20)
*   **Верификация:** Python 3.10 (библиотека `numpy`)

### 1. Требования к окружению
*   Компилятор `g++` (с поддержкой C++17)
*   Установленный `Python 3` с пакетом `numpy` (для проверки)

## Автоматизированная верификация
Для проверки корректности вычислений разработан вспомогательный скрипт на Python. 

**Алгоритм проверки:**
1. Скрипт считывает исходные матрицы.
2. Перемножает их эталонным и оптимизированным методом.
3. Считывает матрицу `C.txt`, созданную нашей C++ программой.
4. Сравнивает матрицы с учетом погрешности округления типов с плавающей точкой.

## Пример работы программы (Консольный вывод)

После успешного выполнения вычислений программа выводит подробный структурированный отчет об объеме задачи, затратах памяти и достигнутой производительности:

```text
========================================
ОТЧЕТ ОБ ОБЪЁМЕ И ПРОИЗВОДИТЕЛЬНОСТИ (2000x2000):
========================================
1. Математическая сложность и Скорость:
   - Всего элементов в одной матрице: 4000000
   - Всего операций (FLOP): ~16000000000 оп.
   - Время расчета алгоритма: 4810.2500 мс (4.810250 сек)
   - ПРОИЗВОДИТЕЛЬНОСТЬ: 3.33 GFLOPS

2. Затраты памяти (ОЗУ):
   - Память под 3 матрицы в программе: 91.55 МБ

3. Объём данных на диске:
   - Размер исходного файла (data/input.txt): 24500.12 КБ
   - Размер файла с результатом (result.txt): 12250.06 КБ
========================================
```

### Как рассчитываются эти метрики в коде

1.  **Всего элементов (`totalElements`):** \(N \times N\)
2.  **Всего операций (`totalOps`):** \(2 \times N^3\) (для каждого из \(N^2\) элементов результирующей матрицы выполняется \(N\) умножений и \(N\) сложений).
3.  **Производительность в GFLOPS (`gflops`):** \(\text{totalOps} / (\text{seconds} \times 10^9)\)
4.  **Затраты памяти в МБ (`ramMegabytes`):** \((3 \times N^2 \times \text{sizeof(double)}) / (1024 \times 1024)\)
5.  **Размер файлов:** Измеряется стандартными средствами C++ (например, через `std::filesystem::file_size`) и переводится в Килобайты (делением на 1024).
